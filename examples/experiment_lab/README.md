# Offline experiment lab

This small standard-library fixture exercises measured experiments without network access,
API keys or a GPU. It is a synthetic regression task, **not a paper reproduction or evidence
of research quality**.

`data.csv` contains fixed train/test rows generated by
`y = 1 + 2x + 0.7x² + 0.03 sin(11x)`, with `x = -3 + 6i/79` for `i=0..79`.
Every fourth row is assigned to the test split. Each run samples 40 training rows with
the declared seed; the test split stays unchanged.

From this directory, run:

```sh
python3 run.py --variant baseline --seed 7
```

The linear baseline produces `metrics.json` and `predictions.json`. The `quadratic`
variant fits a quadratic model; `negative` predicts zero and provides a deliberate
negative result. For manual repeats, remove these generated files before the next run.
Amadeus experiments write outputs inside their own snapshots, leaving this directory
unchanged.

For the CLI, ask the agent to use `run_experiment` with this directory as `cwd` and
`spec.json` as the optional `spec`. For each variant, update `variant`, `seed` and
`parameters` to describe the actual command. Use seeds 7 and 19 for each variant, then call
`compare_experiments` with the two baseline job IDs and the two quadratic job IDs.
Compare the negative variant separately, and export the report using `report_export`.

The observed metric differences describe this fixture. They do not establish statistical
significance, generalization to other data, novelty, or a scientific hypothesis.
