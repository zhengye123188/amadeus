# Amadeus v0.6.2

项目在本版更名为 **Amadeus**，[GitHub 仓库](https://github.com/zhengye123188/amadeus)已使用新名称，npm 发布目标改为 `@lelouch_021015/amadeus`。启动命令仍为 `research`，内部 Python 模块、配置路径、`RESEARCH_*` 环境变量和 `.research` 项目记录保持兼容；无需迁移已有 API 配置和科研数据。

本版将 v0.6.1 的头部特写替换为重新绘制的牧濑红莉栖半身实验室场景。新素材按照选定概念保留托腮姿势、白大褂、红领带、试管架、书本与金色像素十字，三种终端尺寸都展示完整构图。

## 半身场景与窗口布局

[透明 PNG 素材](../assets/kurisu-lab-halfbody-v2.png)与[生成记录](../assets/kurisu-lab-halfbody-v2.prompt.md)保留在仓库中。随包的 `pi/assets/kurisu-pixel.png` 使用同一素材；构建时从完整场景独立生成 32×20、48×32 和 64×40 三份调色板网格，以 schema 3 记录来源和采样信息。运行时直接选择网格，不再使用头部裁剪或对已生成的小网格二次缩放。

| 终端窗口 | 使用的完整半身场景 |
| --- | --- |
| 至少 80 列、24 行 | 32×20 |
| 至少 110 列、36 行 | 48×32 |
| 至少 140 列、44 行 | 64×40 |
| 少于 80 列，或少于 24 行 | 隐藏场景，收紧布局 |

135 列、37 行窗口使用 48×32 场景。含边框的头部最多占一半窗口行数。`research --ui-avatar off`、会话内 `/ui avatar off`、主题切换与单色模式继续可用；`NO_COLOR` 或 `TERM=dumb` 隐藏彩色形象。API 配置、工作区、科研工具、权限、记忆和协作机制沿用原实现。

形象使用 ANSI 半块字符，普通 macOS/Linux 终端无需额外图片协议、运行时图像解码或网络图片下载。大 PNG 是素材预览，字符输出受有限网格、等宽字体的字宽与行高以及终端色彩能力限制，不能呈现大图的全部细节。角色插画是基于用户参考生成的项目素材，不是官方美术；来源和许可边界见[第三方说明](../../THIRD_PARTY_NOTICES.md)。

## 安装与更新

npm 用户需要 Node ≥22.19 和 uv。从原 npm 包迁移时，先卸载旧包以释放 `research` 命令，再安装新包：

```bash
npm uninstall -g @lelouch_021015/research-cli
npm install -g @lelouch_021015/amadeus@0.6.2
research setup
research --version
```

独立安装器自带 Node/Python，启动命令同样为 `research`：

```bash
curl -fsSL https://github.com/zhengye123188/amadeus/releases/latest/download/install.sh | sh
```

退出旧 CLI 后，在目标项目目录运行 `research`。现有配置和科研记录继续保留，更新不会改变 macOS 对项目目录的访问权限。
