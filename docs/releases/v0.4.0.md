# Research CLI v0.4.0

本版复用现成的 Pi 包，继续提供自由对话的科研终端。npm 分发携带科研后端源码；独立安装器包含 Node、Python、npm/npx 和三个内置 Pi 包。PyPI 后端是单独的发布渠道，不影响这两种安装方式。

| 包 | 采用方式 |
| --- | --- |
| `pi-docparser@4.0.0` | 替换 PDF 提取引擎；`import_document` / `download_arxiv` 继续保存来源哈希、页码、chunks 和证据关系。原生三个文档工具不重复暴露。 |
| `pi-web-access@0.35.0` | 提供 `web_search`、`source_check`、`fetch_content`、`get_search_content`；采用前台检索与明确选择页面的方式。 |
| `@upstash/context7-pi@0.1.2` | 提供 `resolve-library-id`、`query-docs`，查询当前库文档和代码示例。 |

默认联网配置为 **53 个科研 MCP 工具、3 个文件工具和6个原生包工具，共62个**。通用记忆和后台进程包不替代科研证据、记忆修订、实验协议/指标及人工确认记录。完整审查与候选包见 [包复用指南](../pi-packages.md)。

新增 `research packages list/install/remove`。安装复用 Pi 的公开包管理器，固定 npm 版本或 Git commit；新包未提供 policy 时保持禁用。policy 明确选择扩展、技能、工具及作用分类，权限与执行开关共用科研 CLI 策略，离线模式不注册联网包工具。当前泛用接入支持工具与 skills，其他生命周期行为需要单独适配。

默认 Pi 状态目录变为 `~/.local/share/research-cli/pi-packages/`，避免混用其他 Pi 安装的配置。旧 `~/.pi/agent` 会话可以明确通过 `--session` 恢复，或设置 `PI_CODING_AGENT_DIR`。配置和状态目录受到文件工具保护。各平台独立安装器通过原生构建和安装检查后由工作流公开发布；构建和发布结果见 [验证记录](../validation.md)。

模型费用预算不包含包服务费用；`/usage` 记录包服务调用与未知费用，不把未知价格当作免费。Context7、网页供应商的配额和账号独立于主模型密钥。工程测试使用模拟模型/服务，不能说明真实模型科研效果。
