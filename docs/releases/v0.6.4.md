# Amadeus v0.6.4

修复调整窗口大小后的字符重排残留，补齐小窗口半身场景，并改进选定概念图的像素采样。启动命令仍为 `research`，API 配置、会话和项目数据保持兼容。

## 窗口缩放与像素

- 缩放结束后强制重绘，覆盖快速缩小又恢复原尺寸的情况；监听和待执行任务在切换、重载、退出时清理。
- 完整半身场景由七档扩展到十四档，新增小尺寸和中间尺寸。窄窗口使用上下布局，短窗口选择较小场景；头部最多占 70% 行数，至少给输入和状态留下 7 行。极小窗口放不下最小场景时显示“窗口过小”。
- 138×41 使用 80 列、26 行，80×24 使用 40 列、13 行，40×24 使用上下布局的 32 列、10 行。没有将半身图裁成头像。
- 四分块参考覆盖区域并保留中心轮廓，回取原图颜色，减少单点采样造成的断裂；合并极低对比区域的噪点。相邻字符复用 ANSI 颜色，每行统一重置，减少重绘数据。

[预览和界面说明](../ui.md)展示真实字符输出的 Menlo 字体模拟图。原始 284×184 概念图保持字节不变；仍使用 ANSI 像素字符，不发送 PNG 图片协议。

## 验证与发布

本机完整 Node 回归及真实 PTY 检查完成。新增终端模拟器测试核对缩放后的最终字符和前景、背景颜色，而非只检查输出里出现过头像；同时与独立的逐字符着色参考对比。原尺寸颜色与可重复生成检查继续保留。测试使用本机模拟模型，不调用用户 API。

npm 和四平台独立安装器发布正在进行；以本节后续更新及 [验证记录](../validation.md) 为准。GUI 字体视觉验收仍未完成，模拟器和 PTY 不能代替用户终端的视觉验收。

```bash
npm install -g @lelouch_021015/amadeus@0.6.4
research setup
research --version
research
```

自带 Node/Python 的安装器发布后，可通过 [GitHub Release](https://github.com/zhengye123188/amadeus/releases/tag/v0.6.4) 下载，或使用仓库的安装入口。已有安装不会随源码推送自动更新；本次不发布 PyPI。
