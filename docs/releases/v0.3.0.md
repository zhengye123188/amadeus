# Research CLI v0.3.0

在项目目录打开终端即可自由对话。此版本补齐从论文证据、代码检查到实测结果对比的工具，保留 Pi 的交互与会话管理，不要求按固定科研流程操作。

- **项目数据**：数据库版本迁移、带校验和的备份、恢复到新工作区。
- **文献与复现**：DOI/arXiv 论文身份、可引用的研究对照图谱、固定代码 commit 的复现计划与阶段核验。
- **实验**：参数、数据哈希、seed、指标定义、基线/候选对比和报告导出；退出 CLI 后仍可运行的独立 worker、重连/取消与显式 checkpoint 文件续跑。
- **代码验证**：项目搜索、Python 符号检查、使用已有依赖运行测试/构建、带冲突检查的文件检查点恢复。
- **可信记录**：假设状态需要明确证据或实测条件，区分执行失败与科学负结果；`/review-memory` 由用户对具体修订确认。
- **配置与用量**：模型能力/价格 profile、显式外部 MCP 配置及工具权限、`/usage` 和软 token/费用预算；未知价格保留为未知。
- **工程验证与可选示例**：12 类模拟科研任务检查产物、引用和工具链；独立的 LIBSVM CPU 开发示例演示参数与结果记录，选参没有超过基线。真实科研效果评估留待具体课题开展后进行。

默认提供 53 个科研 MCP 工具和 3 个 Pi 文件工具；配置 embeddings 后增加 2 个工具。外部 MCP 数量取决于用户显式配置。

独立安装包自带 Node、Python、Pi 和后端依赖，支持 macOS/Linux 的 ARM64 与 x64。升级后运行 `research doctor`；重要项目先运行 `research project backup`。恢复与回退方式见[项目数据说明](https://github.com/zhengye123188/research-cli/blob/v0.3.0/docs/project-data.md)。

工程测试和 mock 评测不代表真实模型科研能力。本次没有付费模型成绩、Docker/GPU 实机验证或完整论文实验复现。暂不支持 Windows、SSH 远程作业、OCR 或多 Agent 调度。
