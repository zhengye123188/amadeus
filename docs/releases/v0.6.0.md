# Research CLI v0.6.0

本版将终端欢迎页改为 Research CLI 自己的像素界面：墨绿面板、薄荷绿文字、琥珀色提示，以及牧濑红莉栖像素头像。用户在项目目录启动后，可直接查看工作区、模型、上下文与协作状态，继续使用原有科研对话和工具能力。

## 像素界面

头像来自随包提供的透明 PNG，预先转换成 48×48 调色板网格。普通终端用 ANSI 半块字符绘制，不需要 Kitty/iTerm 图片协议、运行时图像解码或网络下载。80 列以上且至少 24 行时在头部右侧显示头像；窄窗口隐藏头像，并按宽高收紧布局。中文和长路径按实际显示列裁剪。

```sh
research
research --ui-avatar off
research --ui-theme system
NO_COLOR=1 research
```

会话中支持 `/ui avatar pixel`、`/ui avatar off`、`/ui theme pixel`、`/ui theme system`；`/ui` 查看当前选择。头像选择在当前进程的新建、切换和重载会话中保留，不写入用户配置。显式主题切换沿用 Pi 的偏好保存机制；启动时的默认主题通过临时设置应用。`NO_COLOR` 或 `TERM=dumb` 优先采用单色组件并隐藏彩色头像。

状态栏保留实际模型、上下文占用、Git 分支，以及科研扩展提供的权限、执行、记忆和子 Agent 状态。未知上下文显示 `ctx ?`，费用继续通过 `/usage` 查询。程序只绘制组件背景，终端空白区域的颜色来自用户的终端主题。

## 交互宿主与会话

交互启动改用固定 Pi 0.99.1 的公开 SDK：Research 管理欢迎页、标题和外观，Pi 继续管理编辑、会话、模型、审批和工具循环。输入框继承 `CustomEditor`，保留中文输入、粘贴、多行编辑、历史、命令补全与应用快捷键。

受信任的命名主题资源解决了 `/new`、`/reload` 和会话切换后的配色恢复问题。宿主从 Pi 实际安装的公开 TUI 入口加载组件，使键位和终端能力状态保持一致；恢复选择器使用完整的应用及用户键位。项目扩展、MCP、技能和指令仍需明确选择，没有扩大自动加载范围。

`-p`、JSON、RPC 和工具型命令沿用 Pi CLI，输出不添加像素装饰。`--continue`、`--resume`、`--session` 和 `--fork` 保留原有会话用途；跨项目会话仍需核对工作区。少数上游帮助或退出提示仍可能出现 Pi 名称。

修复新工作区首次启动时，记忆服务和科研后端并发初始化数据库的迁移冲突。迁移在获取 SQLite 写锁后重新核对版本，两个连接均可完成启动；已有数据与异常迁移记录的校验规则保留。

## 科研能力与分发

本次没有新增科研工具。默认联网配置继续提供 **53 个科研 MCP 工具、3 个文件工具、6 个 Pi 包工具和 4 个协作工具，共 66 个**；配置 embeddings 可增加两个工具，离线配置与用户白名单会改变可见集合。六类子 Agent、本地英文/中文 OCR、证据与记忆、结构化实验和权限机制均保留。

npm 安装需要 Node ≥22.19 和 uv，并用 `research setup` 安装包内科研后端。独立安装器计划提供 macOS ARM64/x64、Linux ARM64/x64，内置 Node 22.23.1、Python 3.12.14、Pi、科研后端与三种 OCR 语言数据。npm 和 GitHub Release 分别发布；本次不发布 PyPI。

```sh
# npm 更新；实际可用版本以注册表和 research --version 为准
npm install -g @lelouch_021015/research-cli@latest
research setup
research --version
```

角色插画基于用户选定概念生成，未使用官方游戏或动画原图。角色相关权利属于各自权利人，代码 MIT 许可不授予底层角色权利；可用 `--ui-avatar off` 关闭。[来源说明](../../THIRD_PARTY_NOTICES.md)
