# Research CLI v0.6.1

本版修正终端牧濑红莉栖像素头像的五官模糊问题。原来的胸像经过两次缩小，眼部像素容易丢失；现在使用头部与衣领特写，从原 PNG 分别生成三种终端尺寸，保留双眼细节。npm 包和独立安装器均包含相同修正，用户更新后直接运行 `research`。

## 头像与窗口布局

原始透明 PNG 保持不变。构建时从原图直接采样 20×20、32×32 和 40×40 三份调色板网格，运行时选择匹配的网格，以 ANSI 半块字符绘制，不再缩小已生成的终端网格。普通终端无需额外图片协议、运行时图像解码或网络图片下载。

| 终端窗口 | 使用的头像 |
| --- | --- |
| 至少 80 列、24 行 | 20×20 紧凑特写 |
| 至少 100 列、36 行 | 32×32 特写 |
| 至少 120 列、48 行 | 40×40 精细特写 |
| 少于 80 列，或少于 24 行 | 隐藏头像，收紧布局 |

显示头像时，头部最多占一半窗口行数。`research --ui-avatar off`、会话内 `/ui avatar off`、主题切换及单色模式继续可用；`NO_COLOR` 或 `TERM=dumb` 隐藏彩色头像。字符头像仍受终端字体、色彩能力和窗口尺寸影响。

[像素对比预览](../assets/kurisu-clarity-preview.png)与[头部布局预览](../assets/kurisu-header-preview.png)来自实际网格和组件 ANSI 输出，使用预览字体绘制，不是终端软件截图。角色插画来源和许可边界见[第三方说明](../../THIRD_PARTY_NOTICES.md)。

## 更新已安装版本

npm 用户需要 Node ≥22.19 和 uv。先退出正在运行的 Research CLI，在可访问的目录执行：

```bash
cd ~
npm install -g @lelouch_021015/research-cli@0.6.1
research setup
research --version
```

独立安装器用户执行下面的更新命令；它包含 Node、Python、Pi 和科研后端，更新后无需运行 `research setup`：

```bash
cd ~
curl -fsSL https://github.com/zhengye123188/research-cli/releases/latest/download/install.sh | sh
"$HOME/.local/bin/research" --version
```

版本应显示 `0.6.1 (Pi 0.99.1)`。若同时装有 npm 与独立版本，使用 `command -v research` 核对当前命令路径。已有 API 配置和项目科研数据保留；进入目标项目目录后运行 `research`，当前目录仍作为工作区。macOS 对目标项目所在文件夹的访问权限需要由终端所属应用获得，更新程序不会改变系统隐私权限。

本次没有新增科研工具或更改科研评测范围，Pi 固定为 0.99.1。安装与平台要求见[独立安装器说明](../standalone.md)和[分发说明](../pypi.md)；本次不发布 PyPI。
