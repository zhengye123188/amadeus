# Research CLI v0.2.0

基于 Pi 的交互式科研 CLI。论文检索、代码关联、证据记忆、假设管理和受限实验均可在终端对话中使用。在项目目录打开终端并运行 `research`，当前目录即为工作区。

安装包包含 Node 22.23.1、Python 3.12.14、Pi 0.99.1 和科研后端依赖，无需预装这些环境。支持 Apple Silicon Mac、Intel Mac、Linux x86-64 / ARM64（glibc）。四个平台均经过原生构建和独立安装测试。

## 一条命令安装

```bash
curl -fsSL https://github.com/zhengye123188/research-cli/releases/latest/download/install.sh | sh
export PATH="$HOME/.local/bin:$PATH"
research configure
cd "/你的项目目录"
research
```

下载入口会自动选择平台并核对 SHA-256 后安装。也可以在下方 Assets 下载对应平台的 `.run` 和 `.run.sha256`，然后执行 `sh <安装包路径>`。默认安装在用户目录，无需 sudo。

API 密钥由用户通过 `research configure` 在本机配置，支持 DeepSeek 等 OpenAI 兼容端点。项目数据保存在各项目的 `.research/` 中，API 配置保存在用户目录；更新程序时会保留配置和科研数据。

## 验证与范围

测试覆盖离线安装、包内运行环境、配置保存、Pi/MCP 工具调用、真实终端界面、当前目录作为工作区，以及重装和损坏文件拒绝。模型调用验证使用本地模拟 API，不代表真实科研任务或付费服务效果已验证。

当前不支持 Windows 或 Alpine/musl。macOS 安装包尚未进行 Apple Developer ID 签名或公证。npm / PyPI 采用单独的发布流程，本 Release 只分发 GitHub 独立安装包。
