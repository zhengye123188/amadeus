# Amadeus v0.6.3

本版直接提取用户选定的 284×184 半身概念图像素，替换此前重绘素材的低分辨率字符图。默认使用 Unicode 四分块字符，保留完整人物、托腮手势、白大褂、试管和书本；CLI 仍输出 ANSI 字符，不发送 PNG 图片协议。

## 像素与布局

[概念参考图](../assets/kurisu-concept-reference.png)与随包素材逐字节一致，SHA-256 为 `b452c28928058ddb3d95b030718bd8362f6a8a814ec4fc1920c5cafa74260a62`。预计算数据移除全图 63 色限制，RGB 来自原始像素；每个四分块字符从四个采样子像素中选择两种源颜色近似。七档场景独立从原图采样，最大档保留原图全部 284×184 RGB 像素。

135×37 和 138×41 窗口使用 72 列、23 行的完整场景，四分块对应 144×46 个采样子像素。页眉为左侧文字保留至少 40 列、为对话和编辑保留至少 30% 窗口行数。大窗口可选择更精细的场景，窄窗口和短窗口隐藏头像。

`research --ui-avatar half` 或 `/ui avatar half` 使用半块兼容模式，`pixel` 恢复四分块，`off` 关闭形象。头像字符输出按网格、主题和模式缓存；窗口缩放与重绘会重新选择合适的数据。

[字符预览与定制](../ui.md)使用实际 ANSI 字符和 Menlo 字体绘制，不是终端实机截图。实际效果仍受字体、行距和颜色支持影响；小窗口不能保留原图全部细节，每字符两色也不是任意图片的无损显示。GUI 实机字体检查尚未完成，工程测试不能代替用户终端视觉验收。

## 安装与更新

启动命令仍为 `research`；已有 API 配置、项目数据、会话和模型设置继续沿用。

```bash
npm install -g @lelouch_021015/amadeus@0.6.3
research setup
research --version
```

自带运行环境的安装器：

```bash
curl -fsSL https://github.com/zhengye123188/amadeus/releases/latest/download/install.sh | sh
```

下载前以 [npm 版本页](https://www.npmjs.com/package/@lelouch_021015/amadeus/v/0.6.3) 和 [GitHub Release](https://github.com/zhengye123188/amadeus/releases/tag/v0.6.3) 核对发布状态；当前已安装版本不会因源码更新自动改变。

## 验证

Node 回归测试 99 项通过、2 项可选 OCR 跳过。像素测试逐点核对原尺寸颜色、验证颜色均来自源图及可重复生成，并覆盖两种字符模式、窗口预算、缓存、单色和非交互协议。实际 PTY 检查完成启动、缩放、中文输入、模式切换、新建与重载、主题与退出；没有调用真实模型 API。Python 科研逻辑与工具没有改动。
